# Cellpose 세포 카운팅 프로그램

혈구계산판(Hemocytometer) 화면을 캡처하면 AI(Cellpose-SAM, 사전학습 모델)가 **살아있는 세포**를 세고,
세포 농도 · 총 세포 수 · 희석에 필요한 부피를 바로 계산해 주는 프로그램입니다.

## 다른 PC에 설치하기

1. `CellCounter.exe` 하나만 복사하거나 [Releases](https://github.com/nthusualcoder/cell-counter/releases/latest)에서 내려받아 실행합니다.
2. **처음 실행할 때만** 인터넷으로 Python, AI 라이브러리, AI 모델을 자동 설치합니다.
   - 10~20분 정도 걸립니다. 검은 창이 닫힐 때까지 기다려 주세요.
   - 설치 중 디스크 여유 공간이 약 10GB 필요하고, 설치 후에는 약 7GB를 차지합니다.
   - NVIDIA 그래픽카드가 있으면 GPU 버전을, 없으면 CPU 버전을 설치합니다 (CPU는 분석이 매우 느림).
3. 그다음부터는 `CellCounter.exe`를 실행하면 바로 프로그램이 열립니다.

- 설치 위치: `%LOCALAPPDATA%\CellCounter` (이 폴더를 지우면 제거됩니다)
- 인터넷에서 받은 exe라 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

## 사용법

1. 현미경 프로그램에 세포 화면을 띄웁니다.
2. **[📷 화면 캡처로 바로 카운팅]** → 화면이 어두워지면 **대구획(1 mm × 1 mm) 테두리에 맞춰** 드래그합니다.
3. 자동으로 세포를 세고 결과가 계산됩니다.

저장된 사진은 **[📂 이미지 파일 열기]**로 분석합니다. 카메라 사진 한 장에는 보통 대구획이 1개보다 넓게 찍혀 있으므로,
사진이 열리면 분석할 대구획을 드래그해서 고릅니다 (사진 전체를 쓰려면 Enter, 이때는 **⚙ 추가기능**에서 카운팅한 대구획 수를 맞게 입력).

- 초록 윤곽선: 센 생존 세포 / 노랑: 경계 규칙으로 뺀 세포 (아래·오른쪽 테두리에 걸친 세포)
- 어둡게 염색된 사멸 세포와 이물질은 세지 않습니다.
- 탐지된 세포 수는 직접 고칠 수 있고, 고치면 계산 결과가 바로 바뀝니다.
- 카운팅한 대구획 수(기본 1)와 희석 배수(기본 2)는 **⚙ 추가기능** 버튼을 누르면 나타나며, 여기서 바꿀 수 있습니다.
  기본값과 다르게 바꿔 두면 버튼에 "⚠ 기본값과 다름"이 표시됩니다.

### 계산식

- 세포 농도 (cells/mL) = 세포 수 ÷ 센 대구획 수 × 10⁴ × 희석 배수 (Trypan blue 1:1 → 2)
- 총 세포 수 = 세포 농도 × 현탁액 부피 (cell pellet을 풀어준 media 양)
- 모드 1 (세포 수 채취): 필요한 현탁액 부피 = 목표 세포 수 ÷ 세포 농도
- 모드 2 (새 튜브 제조): 현탁액 투입량 = 목표 농도 × 최종 부피 ÷ 세포 농도, 나머지는 media

농도는 계수판에서 직접 잰 값이라 현탁액 부피와 관계없이 같습니다.
현탁액 부피를 바꾸면 **총 세포 수**가 바뀝니다.

### 속도 (보급형 GPU에서 5초 이내)

GTX 1660 Ti 같은 보급형 GPU에서도 한 번 분석이 5초를 넘지 않도록 다음을 자동으로 합니다.

- GPU 세대에 맞는 16비트 연산: GTX 16xx·RTX 20xx는 FP16, RTX 30xx 이상은 BF16
- 캡처의 세포 크기를 먼저 재서, 세포가 22px보다 크면 22px로 줄여서 분석 (정확도 손실 없음)
- 프로그램을 켤 때 GPU 속도를 재고, 예상 분석 시간이 4.5초를 넘을 때만 이미지를 더 줄임 (세포 11px까지).
  실제 분석 시간을 보고 예측을 계속 보정합니다.

라벨링한 사진 19장 기준 세포 수 오차는 원본 크기 분석 시 평균 2.4%입니다.
GTX 1660 Ti 속도를 가정한 시뮬레이션에서는 대구획 하나(약 1000px) 캡처 기준 평균 2.2~2.5%,
현미경 시야 전체(1368×912) 캡처 기준 평균 3.2~4.6%입니다 (예상 분석 시간 4.5초 이내).
결과 창에 매번 실제 분석 시간이 표시됩니다.

## 업데이트

- 프로그램의 **[🔄 업데이트 확인]** 버튼을 누르면 GitHub에서 최신 버전을 받아 다시 시작합니다.
- 새 버전이 있으면 프로그램을 켤 때 버튼이 주황색(🔔)으로 바뀝니다.

### 코드를 고친 뒤 다른 PC에 배포하기 (관리자용)

1. 이 폴더에서 코드를 수정합니다.
2. `publish_update.bat`을 더블클릭하고 변경 내용을 한 줄로 적습니다.
   - `VERSION`이 자동으로 올라가고 GitHub(main 브랜치)에 업로드됩니다.
3. 다른 PC에서 **[업데이트 확인]**을 누르면 반영됩니다 (GitHub 반영까지 몇 분 걸릴 수 있음).

- `requirements.txt`(라이브러리 목록)를 바꾸면 다른 PC는 업데이트할 때 라이브러리도 자동으로 다시 설치합니다.
- 런처(`launcher/CellCounterLauncher.cs`)를 고쳤다면 `launcher/build.bat`으로 exe를 다시 만들고,
  GitHub 저장소의 Releases에 새 릴리스로 올리거나 다른 PC에 직접 복사하세요.
- 다른 PC에서 이 폴더를 처음 받을 때: `git clone https://github.com/nthusualcoder/cell-counter.git`

## 폴더 구성

| 파일 | 역할 |
| --- | --- |
| `01_cellpose_gui.py` | 프로그램 화면 (PySide6) |
| `cellpose_counter.py` | 세포 탐지·생존 세포 판별·농도 계산 (명령줄로도 실행 가능) |
| `updater.py` | 설치·업데이트 (GitHub에서 최신 코드 받기) |
| `launcher/` | `CellCounter.exe` 소스와 빌드 스크립트 |
| `tools/evaluate_accuracy.py` | 라벨링한 사진으로 정확도 확인 |
| `VERSION`, `requirements.txt` | 버전 번호, 필요한 라이브러리 |

세포 사진(`train_data/`), 라벨(`labels/`), AI 모델, 예전 배포 폴더(`Cellpose_Deploy/`)는 용량 때문에 GitHub에 올리지 않습니다.
